# OpenBoxHub v1.0.2

## 简体中文

本次更新为参数化收纳盒工作台加入完整中英文界面、GitHub 项目入口和 MIT 项目许可。

- 页头可在「简体中文」与「English」之间切换；默认中文，可通过 `?lang=en` 直接打开英文界面。切换会保留当前参数、合并布局、独立零件设置、选择与预览状态。
- 参数面板、零件编辑、三维控件、帮助、导入导出提示、错误与可访问名称均支持英文。语言选择只更新界面及 URL，不保存设计到浏览器存储。
- 新增 GitHub 图标入口、完整英文 README、双向语言链接与多语言维护约定。
- 项目代码采用 MIT 许可，Copyright (c) 2026 geekheart。构建从根 `LICENSE` 自动生成 `dist/LICENSE`；第三方依赖保留各自许可和来源说明。

CAD 几何、打印方向、JSON 格式、稳定零件 ID 和文件名保持兼容。导出文件内原有零件名称、元数据和 ZIP 说明保持既有格式，不随界面语言改变。所有建模与文件生成仍在浏览器内完成。

验证：Node.js 24 / pnpm 11.19.0 下，67 项测试中 66 项通过，1 项需要原生 FreeCAD 环境的检查跳过；TypeScript 检查和生产构建通过。新增回归覆盖语言 URL、实际组件渲染、核心诊断以及文件名与设计数据保留。本次不涉及 CAD 几何修改，也未新增实物试打验证。

[中文说明](https://github.com/geekheart/OpenBoxHub/blob/v1.0.2/README.md) · [在线工作台](https://geekheart.github.io/OpenBoxHub/)

## English

This release adds a bilingual interface, a GitHub project link and an MIT project license to the parametric storage box workshop.

- Switch between **简体中文** and **English** in the header. Simplified Chinese remains the default; `?lang=en` opens English directly. Switching retains parameters, merged layouts, individual part settings, selection and preview state.
- Parameter panels, part editing, 3D controls, help, import/export messages, errors and accessible names support English. Language selection changes only the interface and URL; it does not save designs in browser storage.
- Add the GitHub icon link, a complete English README, reciprocal language links and multilingual maintenance guidelines.
- License the project code under MIT, Copyright (c) 2026 geekheart. The build emits `dist/LICENSE` from the root `LICENSE`. Third-party dependencies retain their separate licenses and source notices.

CAD geometry, printing orientation, JSON format, stable part IDs and filenames remain compatible. Existing part names, metadata and ZIP instructions inside exported files retain their established format independently of the interface language. Modeling and file generation remain entirely in the browser.

Validation: with Node.js 24 and pnpm 11.19.0, 66 of 67 tests passed; one check requiring a native FreeCAD environment was skipped. TypeScript checks and the production build passed. New regression coverage includes locale URLs, actual component rendering, engine diagnostics, and preservation of filenames and design data. This release makes no CAD geometry changes and adds no physical print validation.
